# 🗺️ 개발 로드맵 및 아이디어

## 📦 프로그램 모듈 및 강사 연동 (New)
*   🔗 **프로그램 - 강사 매칭 자동화**: 강사 관리 페이지와 연동하여, 강사별 '가능한 수업(프로그램)' 데이터를 연결하고, 일정 배정 시 해당 프로그램을 진행할 수 있는 강사만 필터링하여 드롭다운으로 제공.
*   📋 **프로그램 다중 사진 갤러리 뷰**: 교육계획안 출력 시 첨부된 예시 사진들이 깔끔하게 격자 형태로 자동 정렬되어 출력되도록 템플릿 고도화.
*   🗂️ **교구/재료 재고 관리 (Inventory)**: 각 프로그램에 필요한 교구 리스트와 학원의 실제 교구 재고 수량을 매핑하여 부족한 교구 알림 기능 추가.
## 📱 현장성 및 편의성 강화
*   🌐 PWA(Progressive Web App): 모바일 접근성 및 현장 안내 기능 강화
*   🗺️ 지도 연동: 카카오맵/네이버 지도 API를 활용해 출강 학교 위치 및 길찾기 안내 연동
*   🔔 강사 알림 서비스: 일정 전날 또는 당일 푸시 알림/SMS 연동

## 💰 정산 및 통계 관리
*   ~~💵 강사료 정산 자동화: 입력된 시간과 단가를 기반으로 월별 예상 강사료 자동 계산 기능~~ (✅ 완료)
*   📥 **정산 내역서 Excel/PDF 내보내기 (추가 아이디어)**: 정산 관리 페이지에서 조회된 내용을 엑셀 형식(XLSX)이나 PDF로 출력하여 회계 및 세무 처리에 직접 사용할 수 있도록 내보내기 기능 추가.
*   📊 통계 데이터 시각화: 지역별, 학교별 출강 빈도 및 매출 통계 대시보드 구축 (누적 출강료 확인 포함)
*   📈 학교별 총 출강 횟수 및 누적 강사료 요약 정보 표시

## 🛡️ 데이터 관리 및 고도화
*   ✅ 데이터 유효성 검사: 전화번호, 이메일 형식 등 입력 데이터의 정확성 검증 로직 추가
*   🔒 **Firebase 보안 규칙(Security Rules) 강화 (필수)**: 프론트엔드에서 DB에 직접 접근하는 서버리스 구조의 취약점을 보완하기 위해, `request.auth != null` 뿐만 아니라 특정 관리자 권한을 가진 계정만 `instructors`와 `schedules` 문서를 읽고 쓸 수 있도록 보안 규칙 락(Lock) 적용.
*   🔐 **개인정보 마스킹 및 암호화 (추가 아이디어)**: 계좌번호 등 민감 정보가 화면에 노출될 때 중간 자리를 마스킹(`***`) 처리하거나, DB 저장 시 앱 단에서 암호화 후 저장하는 방식 도입.
*   📄 일정 데이터 엑셀/PDF 내보내기: 특정 학교나 기간별 출강 이력을 문서화하여 공유할 수 있는 기능

## ⏰ 강사 일정 및 배정 고도화
*   **캘린더 시각적 차단 기능 (Visual Block)**: 스케줄을 추가할 때 캘린더 타임 슬롯 자체에서 특정 강사의 불가능 시간을 회색(블러) 처리하여 겹치게 드래그 앤 드롭하지 못하게 하는 UI 직관성 개선.
*   **강사 배정 최적화 추천 (AI/알고리즘)**: 새 일정을 등록할 때 조건(시간, 요일, 프로그램)에 맞는 '수업 가능한' 강사 리스트만 필터링해서 드롭다운 상단에 추천해 주는 기능.
*   **가용 시간 대비 근무량 통계**: 주당 수업 가능 시간 대비 실제 배정된 시간 비율(가동률)을 계산하여, 어떤 강사에게 여유가 있는지 한눈에 볼 수 있는 매니저용 통계 대시보드 추가.

## 💡 아이디어 (보류 또는 구상 중)
*   **강사별 특별 지급기준 관리**: 특정 강사의 경력이나 자격 요건에 따라 기본 지급기준보다 더 높거나 다른 금액을 지급해야 할 경우, 강사별 프로필에 '예외 강사비 테이블'이나 '할증 퍼센트(%)'를 설정하는 기능.
*   **월별 적용 통계 대시보드**: 정산 내역 페이지에서 이번 달에 진행한 수업이 초등학교/중학교/고등학교별로 몇 차시인지 통계를 한눈에 보여주는 시각화 차트 추가.
*   🤖 데이터 입력 편의성 개선: 출강 이력 입력 시 '학교관리' 데이터를 기반으로 한 자동 완성(Autocomplete) 또는 드롭다운 선택 기능
*   📝 학교관리 페이지에서 조회된 학교 데이터를 사용자 친화적으로 직접 수정 (삭제는 웹에서는 절대 불가) 기능 고도화
*   🏷️ '학교관리' 시트에서 검색용 약칭 정리 (일괄 작업)

## 🧩 UI/UX 최적화 및 공간 활용 (신규 아이디어)
*   **대시보드 위젯 타일형 구조 전환**: 현재 흩어져 있는 각종 조회 조건 및 검색 필터를 모던한 위젯 형태의 그리드로 압축하여 시각적 피로도를 줄이고 콤팩트한 패널 느낌으로 구성.
*   **월별 강사 총합계 툴팁(Tooltip)**: 강사 목록의 이름에 마우스를 올리면 클릭하지 않고도 해당 월의 총 근무일수와 강사료 합계를 미리 보여주는 프리뷰 기능.
*   **우측 빈 공간 활용 (미니 스케줄러)**: 왼쪽 조회/검색 패널이 길어지고 우측 프로필 카드 아래에 빈 공간이 남을 경우, 선택된 강사의 이번 달 핵심 일정을 보여주는 '미니 캘린더 형태의 요약 뷰어'를 배치하여 공간 활용도를 극대화.
*   **모달 애니메이션 전역 모듈화**: 이중 `requestAnimationFrame` 같은 렌더링 최적화 코드가 각 페이지별 JS에 분산되어 있으므로, 이를 `utils.js` 등 공통 모듈로 분리하여 코드의 중복을 줄이고 유지보수성을 향상.
